## Plataforma de Conversão e Análise Dimensional de E&M

Aplicação web local em Python/Streamlit integrada ao motor **GNU Units**.

## Destaques
- **Padrão Acadêmico IUPAC / E. Richard Cohen:** Unidades em fonte reta ('\\text{...}') e potências negativas em denominadores.
- **Análise Dimensional Formal:** Mapeamento para dimensões fundamentais $[X] = Mâ L^b T^c I^d$.
- **Uso Local:**Execução rápida e offline.
